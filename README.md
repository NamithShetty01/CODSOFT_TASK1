# 🤖 CODSOFT Task 1 - Rule-Based Chatbot

A simple rule-based chatbot developed in Python as part of the CodSoft Artificial Intelligence Internship.

## 📌 Project Description

This project is a rule-based chatbot that responds to user inputs using predefined rules, conditional statements, and keyword pattern matching.

The chatbot can:

- Respond to greetings
- Tell its name
- Respond to "How are you?"
- Display the current time
- Display today's date
- Tell random programming jokes
- Display a help menu
- Handle unknown inputs
- Exit the conversation when requested

## 🛠️ Technologies Used

- Python 3
- `datetime` module
- `random` module

## ⚙️ Features

### 1. Greeting Detection

The chatbot recognizes greetings such as:

- Hello
- Hi
- Hey
- Good morning
- Good afternoon
- Good evening

### 2. Basic Conversation

The chatbot can answer questions such as:

- What is your name?
- Who are you?
- How are you?

### 3. Date and Time

The chatbot can provide:

- Current time
- Current date

### 4. Programming Jokes

The chatbot randomly selects a programming-related joke from a predefined collection.

### 5. Help System

Users can type `help` to see the available commands and questions.

### 6. Exit Commands

The conversation can be ended using:

```text
bye
exit
quit
